> Monstermon Bronze

A retro monster battler for the browser, built by a five-person team over eight weeks of Scrum sprints for CS 345. I led UI development and built much of the interface.

Click the game to give the frame focus and then follow on-screen instructions for the controls.

Source on GitHub Open the game on its own

01. About the project

Five of us built the game in JavaScript with p5.js, working in Scrum sprints over eight weeks. The interface is a single class that switches between screens, including the splash, monster selection, and battle screens.

I led the UI work. That covered the screens, the menus, and the battle display, including the roster panel along the bottom of the battle screen. If I had to do it again I would break the UI class down further.

Art and sound credits are in the credits folder of the repository.

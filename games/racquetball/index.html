> Racquetball

A JavaScript game from a CS 345 lab, built with p5.js. Version 2 puts everything in one file. Version 3 splits it into classes and goes beyond the original spec. Both are playable below.

Click a game to give it keyboard focus, then use the up and down arrow keys.

01. Compare and contrast

AspectVersion 2Version 3
Structure One file with Racquet, Ball, and Game One file per class, with JSDoc comments, plus a separate UserInterface class
Arena 600 × 400 800 × 600, with a racquet guide along the right side
Scoring Score only. A miss costs a point. Score, round high score, and five lives with a game over screen
Controls Arrow keys Arrow keys, plus pause and unpause with Escape and a full reset with the backtick key
Screens Gameplay only Pause screen with rules and controls, and a game over screen

Same logic, different home

In v2, the bounce logic sits inline in Game.play(). In v3, play() reads as a list of steps and the bounce logic moves into its own boundary() method. The UI also moves out into UserInterface.

v2: Game.play() 
play() {
  this.racquet.show();
  this.racquet.move();
  // TODO add Ball

  this.ball.show();
  this.ball.move();

  // bounce conditions
  if(this.ball.getY() <= this.upperBound || this.ball.getY() >= this.lowerBound) {
    this.ball.bounceY();
  }

  if(this.ball.getX() <= this.leftBound) {
    this.ball.bounceX();
  } else if(this.ball.getX() >= (this.racquet.getEdge() - this.ball.getRad())) {
    if(this.ball.getY() >= this.racquet.getTop() && this.ball.getY() <= this.racquet.getBottom()) {
      this.ball.bounceX();
      this.increaseScore();
    } else {
      this.decreaseScore();
      this.reset();
    }
  }
}
v3: Game.play() 
play() {
  if(!this.started) {
    game.pause();
  }
  if(this.outOfLives) {
    game.gameOver();
  }
  // show and move racquet
  this.racquet.show();
  this.racquet.move();

  // show and move ball
  this.ball.show();
  this.ball.move();

  // bounce ball off bounds
  this.boundary();

  // if isPaused(), show pause screen. Else, show score in top left.
  if(this.isOver()) {
    this.ui.gameOverScreen();
  } else if(this.isPaused()) {
    this.ui.pauseScreen();
  } else {
    this.ui.showScore();
  }

  // set high score
  this.setHighScore();
}

02. Features

Original specifications

  • The player controls a tall, thin rectangle on the right side of the screen and moves it up and down with the arrow keys.
  • A ball launches from the left side at a diagonal.
  • Each time the player bounces the ball back, they get a point.
  • If the ball goes past the right side, the player loses a point and the ball launches again.
  • The ball bounces off the top, bottom, and left side.
  • The score shows at the top left.

Added in v3

  • Pause and unpause, with a pause screen
  • Round high score
  • Racquet guide on the right side of the arena
  • Larger arena, with faster ball and racquet
  • New colors
  • Lives with a game over condition

Future features

  • Full screen mode
  • Persistent high scores with user names
  • A mode where ball speed increases gradually with score
  • Adjustable window size
  • Difficulty levels
  • Reworked bounce mechanics, so racquet velocity transfers to the ball
